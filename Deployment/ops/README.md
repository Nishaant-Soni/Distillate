## `Deployment/setup_gcp.sh`

This script sets up everything the project needs in GCP. A project owner runs it, and running it again is safe:

```bash
PROJECT=distillate-mlops Deployment/setup_gcp.sh
```

It enables the APIs, then creates whatever is missing:

* the bucket
* the Artifact Registry repositories
* the service accounts and their roles
* Workload Identity for GitHub Actions
* the Secret Manager secrets
* the `distillate-api` Cloud Run service
* both VMs

Anything that already exists is kept. The header of the script lists every step.

**Who gets what:**

| Identity | Used by | Can |
|---|---|---|
| `vertex-trainer` | Vertex AI training jobs | read the bucket, write `ci/`, write logs |
| `github-ci` | model-ci, deploy.yml | push images, publish packages, start jobs as `vertex-trainer`, use `ci/`; build with Cloud Build, deploy revisions and move traffic on Cloud Run (`run.developer`), run the service as `distillate-api`, append to `deployments/` |
| `mlflow-server` | MLflow VM | read and write `mlflow/` |
| `distillate-api` | Cloud Run runtime | nothing (Cloud Run writes its logs and metrics itself) |
| `distillate-ops` | ops VM: Airflow, retrain_dag | read and write the bucket, submit Vertex jobs as `vertex-trainer`, read `distillate-images`, publish to `distillate-models`, read Cloud Monitoring, read the five secrets |
| `distillate-frontend` | demo app | `Deployment/frontend/setup_frontend.sh` |

**Secrets:**

| Secret | Filled by | Read by |
|---|---|---|
| `mlflow-password` | hand, once | ops VM, deploy.sh outside CI, demo app |
| `github-dispatch-token` | hand, once: fine-grained token, this repository, Contents read and write | ops VM (retrain_dag's `repository_dispatch`) |
| `slack-webhook-url` | hand, once | ops VM (Airflow alerts) |
| `airflow-admin-password`, `grafana-admin-password` | generated by the script | ops VM |

Fill a secret with this command. `printf '%s'` adds no newline, which would break a password:

```bash
printf '%s' '<value>' | gcloud secrets versions add <name> --project distillate-mlops --data-file=-
```

## The ops VM (`distillate-ops`)

The ops VM is an e2-standard-2 (8 GB of RAM) with 4 GB of swap. It runs as `distillate-ops` and has no key files.

`startup.sh` runs on every boot:

* **First boot only:** installs Docker and DVC, clones the repository and runs `dvc pull` for the processed data (about 250 MB).
* **Every boot:**
  * updates the clone to `origin/main`
  * writes `.env` files from Secret Manager (root-only, mode 600)
  * starts Airflow with `airflow.ops.yaml` and the monitoring stack with `monitoring.ops.yaml`

On the first boot, building Airflow's image takes about 20 minutes.

**Day-to-day commands:**

```bash
# Follow the startup script
gcloud compute ssh distillate-ops --zone us-east1-b --project distillate-mlops \
  -- sudo journalctl -fu google-startup-scripts.service

# Airflow UI: not exposed; tunnel it to http://localhost:8080 (user admin)
gcloud compute ssh distillate-ops --zone us-east1-b --project distillate-mlops -- -N -L 8080:localhost:8080
gcloud secrets versions access latest --secret airflow-admin-password --project distillate-mlops

# Grafana: http://<ops VM external IP>:3000 (user admin)
gcloud secrets versions access latest --secret grafana-admin-password --project distillate-mlops

# After filling a secret or changing startup.sh
gcloud compute instances reset distillate-ops --zone us-east1-b --project distillate-mlops
```

**Firewall:** only Grafana's port 3000 is open to the internet, and Grafana has a login with no anonymous access. Airflow (8080) and Prometheus (9090) listen on the VM itself only.

**Cost:**

* An e2-standard-2 costs about $0.067 an hour, so about $1.60 a day.
* The 60 GB balanced disk costs about $6 a month.
* The nightly shutdown is off from Nov 25 to Dec 7 (work plan 6.1).
